# Interactive 3D Smart City (Unity)

An interactive 3D environment of a smart city built in Unity, featuring dynamic weather systems and real-time atmospheric transitions.

## 🌟 Features
* **Dynamic Weather System:** Seamlessly transition between three distinct environmental states:
    * ☀️ **Normal:** Clear skies with high visibility and standard lighting.
    * 🌧️ **Rain:** * **Atmospherics:** Particle-based precipitation and darkened skybox.
        * **Interactions:** "Umbrella Open" animations for pedestrians and automatic streetlights activation due to low sunlight.
    * 🏜️ **Dust:** * **Atmospherics:** Reduced visibility with heavy orange/brown fog and wind-blown dust particles.
        * **Smart Logic:** Automatic activation of "Clear Air Systems" in buildings with visible filtration VFX.

## 🛠️ Built With
* **Unity Version:** 6000.0.37f (Unity 6)
* **Render Pipeline:** Universal Render Pipeline (URP)
* **Language:** C#
